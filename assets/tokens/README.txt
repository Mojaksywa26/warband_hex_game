Token illustrations

Place optional transparent PNG portraits in this directory.
Assign them in tokens.csv using paths such as assets/tokens/anvilhead.png.

Portraits are center-cropped into the inner hex on board and setup Tokens.
Empty illustration fields retain the existing text glyph. A failed PNG load
also restores the glyph automatically. Attack, Shield, Initiative, effect,
and wound overlays remain independent of the illustration.
